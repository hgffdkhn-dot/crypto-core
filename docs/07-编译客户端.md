# 编译 Android 客户端

服务端自检全绿之后，这一步把 APK 编出来装到手机上。

---

## 0. 编译前确认三件事

打开 `app/build.gradle.kts`，确认这三行和你的服务器一致：

```kotlin
buildConfigField("String", "DEFAULT_HOST",           "\"https://server.servebeer.com\"")
buildConfigField("String", "SERVER_ED25519_PUB_B64", "\"sci64uPNph+ql/Xi+upQdQRF1DuP3PflczCZVrI9G6Q=\"")
buildConfigField("String", "SERVER_X25519_PUB_B64",  "\"id+vFwFJbctVUeBhZsSmSf22HjhmOCSATGrDO567s10=\"")
```

**任一不符，装上去也会一直显示「连接中…」。**

公钥来源（如果换了服务器，重新取）：

```bash
journalctl -u enchat --no-pager | grep -A3 '服务器长期公钥'
```

---

## 1. 准备环境

- **JDK 17**（不是 8，不是 21 —— AGP 8.5 要求 17）
- **Android Studio** Hedgehog（2023.1.1）或更新，或者独立安装 Android SDK（compileSdk 34 + build-tools 34.0.0）
- 磁盘留 **≥ 10 GB**（Gradle 缓存 + Android SDK）

用 Android Studio 的话，直接 **File → Open** 选项目根目录即可，SDK 会自动提示安装。

命令行方式需要 `local.properties` 指向 SDK：

```bash
echo "sdk.dir=$HOME/Android/Sdk" > local.properties    # Linux/Mac
# Windows: echo sdk.dir=C:\\Users\\你的用户名\\AppData\\Local\\Android\\Sdk > local.properties
```

> 项目 `settings.gradle.kts` 里 `:app` 是「检测到 SDK 才纳入」。
> 没设 `ANDROID_HOME` 也没建 `local.properties` 的话会跳过 Android 模块 ——
> 这是为了让纯 JVM 模块在无 SDK 环境也能编译，不是 bug。

---

## 2. 编译

### 第一次建议编 debug

```bash
./gradlew :app:assembleDebug
```

产物：`app/build/outputs/apk/debug/app-debug.apk`

**为什么先编 debug**：release 开了 R8 混淆，会多一层变量。先确认代码本身没问题，再上 release。

Windows 用 `gradlew.bat`：

```
gradlew.bat :app:assembleDebug
```

### 确认可用后再编 release

release 需要签名，先建个密钥库（**只做一次，文件务必备份**）：

```bash
keytool -genkeypair -v -keystore enchat.jks -keyalg RSA -keysize 2048 \
  -validity 10000 -alias enchat
```

然后在 `app/build.gradle.kts` 的 `android { }` 里加：

```kotlin
signingConfigs {
    create("release") {
        storeFile     = file("../enchat.jks")
        storePassword = "你的密钥库口令"
        keyAlias      = "enchat"
        keyPassword   = "你的密钥口令"
    }
}
buildTypes {
    release {
        signingConfig = signingConfigs.getByName("release")
        // ... 其余保持
    }
}
```

```bash
./gradlew :app:assembleRelease
```

产物：`app/build/outputs/apk/release/app-release.apk`

> 口令别硬编码进仓库。正式做法写在 `~/.gradle/gradle.properties` 或走环境变量。

## 3. 安装到手机

```bash
# 手机开 USB 调试，连电脑
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

或者直接把 APK 传到手机，点开安装（需要允许「未知来源」）。

**最低系统版本**：Android 8.0（API 26）。

---

## 4. 装完怎么验

1. 打开 App → 注册一个账号（用户名 + 口令，口令支持字母数字符号，8–64 位）
2. 注册成功即登录，顶部**不应**出现「连接中…」或「正在等待网络…」
3. 记下自己的 UID（设置页能看到）
4. 用另一台手机或模拟器注册第二个账号，互相加好友
5. 聊天页右上角 → **启用高级加密聊天** → 返回列表会多出一条端到端会话 → 点进去应弹出带锁图标的对话框

如果第 2 步卡在「连接中…」，看下方排障。

## 5. 排障

### 一直显示「连接中…」

按顺序查：

```bash
# 服务端有没有收到连接
journalctl -u enchat -f
```

| 现象 | 原因 | 处理 |
|---|---|---|
| 日志完全没动静 | 请求没到服务端 | 手机网络 / DNS / 防火墙 |
| 有连接但立刻断 | 公钥 pin 不匹配 | 核对 build.gradle.kts 里的两个公钥 |
| 报 `TRANSPORT_DECRYPT_FAILED` | 客户端服务端版本不一致 | 两边都用最新代码 |

### 显示「正在等待网络…」

手机本身没网，不是服务端问题。这是设计好的状态区分：
无网 → 等待网络；有网未连上服务器 → 连接中。

### 编译报错

**`This version of the Compose Compiler requires Kotlin x.y`**
→ Kotlin 与 Compose Compiler 版本不匹配。见 `gradle/libs.versions.toml` 里的对照注释。

**`Plugin[id:'com.android.application'] was not found`**
→ 已修（settings.gradle.kts 加了 `google()`）。若仍出现，检查网络能否访问 `dl.google.com`。

**kapt / Room 相关**
→ 看 `docs/05-构建踩坑与修复.md` §6.9。

## 6. 已知未验证项

1. **`bcprov-jdk18on` 在真机上的表现未实测**。Android 项目更常用 `bcprov-jdk15to18`。
   若运行时出现 `NoClassDefFoundError`（尤其是注册/登录或启用端到端加密时），
   把 `gradle/libs.versions.toml` 里改成 `bcprov-jdk15to18:1.78.1` 即可 —— 两者 API 完全一致。

2. **release 混淆未实测**。已补齐 BouncyCastle / org.json / Room 的 keep 规则，
   但 R8 行为需真机验证。**首次建议先用 debug 装**，确认功能正常再上 release。

3. **群聊 UI 未完成**（服务端已实现并测试）。客户端只有入口占位。

4. **头像图片选择器未做**，目前只能走默认头像。

5. **推送通知未做**，App 在后台时收不到消息，打开后才同步。
